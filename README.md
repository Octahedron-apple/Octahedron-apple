# 💫 About Me:
Hi there. I'm a software developer with a strong focus on AI integrations and crafting custom tooling. 

### 🎯 What I Do
I build a wide variety of projects, from agentic tooling and custom **3D rendering engines** to CLI utilities (usually working from my NixOS setup).

### 🧪 My Approach to Code
I value software reliability and aim to write maintainable, robust code. I practice **Test-Driven Development (TDD)** to help ensure that my logic is well-tested before it reaches production.

### 🔭 AI Ecosystem
I built an autonomous **AI Agent ecosystem** combining [**Linerun**](https://github.com/Octahedron-apple/LineRun) (a sandboxed code runner), [**DotDB**](https://github.com/Octahedron-apple/DotDB) (a local vector database), and [**PlaneMCP**](https://github.com/Octahedron-apple/PlaneMCP) for tool integration.

### 🚀 Notable Projects
My notable projects include [**Linerun**](https://github.com/Octahedron-apple/LineRun), [**DotDB**](https://github.com/Octahedron-apple/DotDB), [**PageShell Studio**](https://github.com/Octahedron-apple/PageShell-Studio) (a browser-native AI assistant), [**Circ-Maker**](https://github.com/Octahedron-apple/Circ-Maker) (a Logisim circuit generator), [**i-shall**](https://github.com/Octahedron-apple/i-shall) (a custom UNIX shell in Go) with its [**VTerm**](https://github.com/Octahedron-apple/VTerm) web interface, [**Mesh-Agent**](https://github.com/Octahedron-apple/Mesh-Agent) (a sandboxed AI Agent), [**stunning-train**](https://github.com/Octahedron-apple/stunning-train) (a terminal RSVP reader), [**Wiki-Links-Tree**](https://github.com/Octahedron-apple/Wiki-Links-Tree), a [**Chat with PDF**](https://github.com/Octahedron-apple/Chat-With-PDF) application, an [**AI File Organizer**](https://github.com/Octahedron-apple/AI-File-Organizer) powered by local LLMs, and a [**Basic-3D Engine**](https://github.com/Octahedron-apple/Basic-3D) built entirely without external 3D libraries.

### ⚡ Fun Fact
I once built an AI calculator that solves arithmetic problems by treating math equations as NLP text classification tasks.
